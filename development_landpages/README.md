# Landpages Para Analise De Desenvolvimento

Protótipos HTML estáticos e independentes para comparação visual, técnica e de copy.

## Páginas

- `index.html` — hub comparativo com links, checklist e matriz de análise.
- `marketing-agency/index.html` — agência de marketing focada em growth, mídia paga e CRO.
- `tourism-agency/index.html` — agência de turismo focada em roteiros personalizados e suporte.

## Como abrir

Abra os arquivos HTML diretamente no navegador ou use um servidor local:

```bash
python3 -m http.server 8080
```

Depois acesse:

- `http://localhost:8080/development_landpages/`
- `http://localhost:8080/development_landpages/marketing-agency/`
- `http://localhost:8080/development_landpages/tourism-agency/`
